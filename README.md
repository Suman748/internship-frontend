# Internship Frontend

React + Vite frontend.

## Requirements
- Node.js 20 or newer
- npm

## Setup
1. Clone the repo:
   ```bash
   git clone https://github.com/Suman748/internship-frontend.git
   cd internship-frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Open the address shown in the terminal, usually http://localhost:5173

## Notes
- Keep the terminal open while using the app. The page stops loading if the server is stopped.
- Run these commands inside the frontend folder, which contains `package.json`.

## Stop
Press `Ctrl+C` in the terminal.
